# ReadFish 自动阅读功能方案

## 一、功能概述

为 ReadFish 阅读器添加自动阅读功能，支持自动翻页、速度调节、快捷键控制等功能，同时优化目录页面定位功能，提升用户阅读体验。

---

## 二、需求分析

### 2.1 核心功能需求

1. **速度设置**
   - 在配置窗口中添加自动阅读速度设置项
   - 支持自定义翻页间隔（单位：秒/页）
   - 提供合理的默认值

2. **右键菜单控制**
   - 添加"开始自动阅读"菜单选项
   - 自动阅读时，菜单变为"停止自动阅读"
   - 点击可切换自动阅读状态
   - 添加"查看目录"按钮，点击后打开目录页面并自动定位到当前章节

3. **快捷键控制（需要阅读器有焦点）**
   - `Ctrl + A`：开始/关闭自动阅读
   - `空格`：在自动阅读状态下，暂停/恢复自动阅读（仅在开始后生效）
   - `↑`（上方向键）：加快自动阅读速度
   - `↓`（下方向键）：减慢自动阅读速度

4. **自动翻页逻辑**
   - 复用现有的 `page_down()` 方法进行翻页
   - 兼容单行模式和多行模式
   - 到达文件末尾时自动停止
   - 自动阅读时按正常逻辑保存阅读历史

5. **窗口隐藏/显示联动**
   - 自动阅读时，窗口隐藏后自动暂停
   - 窗口重新显示后自动恢复自动阅读

6. **目录页面自动定位**
   - 从书架进入目录页面时，自动定位到当前正在阅读的章节并高亮/选中
   - 从阅读器右键菜单打开目录页面时，自动定位到当前正在阅读的章节并高亮/选中

### 2.2 功能排除

- ❌ 不做任何弹窗通知功能（Toast 通知）
- ❌ 不添加任何状态提示的视觉元素（避免干扰阅读）

### 2.3 新增功能：快捷键说明

在配置窗口中添加快捷键说明区域，列出所有可用的快捷键：

**阅读器快捷键：**
- `Ctrl + E`：显示章节进度
- `Ctrl + F`：打开搜索窗口
- `Ctrl + I`：打开设置窗口
- `Ctrl + A`：开始/关闭自动阅读
- `Ctrl + Q`：退出应用
- `Ctrl + \`：临时固定显示阅读器
- `ESC`：关闭阅读器窗口
- `↑` / `PageUp`：上一页（或加快自动阅读速度，当自动阅读时）
- `↓` / `PageDown`：下一页（或减慢自动阅读速度，当自动阅读时）
- `空格`：暂停/恢复自动阅读（仅在自动阅读时有效）

**通用说明：**
- 所有快捷键需要阅读器有焦点才能生效
- 自定义翻页按键可在配置中设置（额外支持）

## 三、技术实现方案

### 3.1 文件修改清单

需要修改以下文件：

1. **`config_manager.py`** - 添加自动阅读相关配置项
2. **`config_window.py`** - 添加自动阅读速度设置界面和快捷键说明区域
3. **`reader_window.py`** - 实现自动阅读核心逻辑和右键菜单"查看目录"功能
4. **`contents_window.py`** - 实现目录页面自动定位和高亮功能

### 3.2 详细实现步骤

#### 步骤 1：更新配置管理器 (`config_manager.py`)

在 `default_config` 中添加：

```python
# 自动阅读设置
'auto_read_speed': 2.0,  # 自动阅读速度（秒/页），默认 2 秒
'auto_read_speed_min': 0.5,  # 最小速度
'auto_read_speed_max': 10.0,  # 最大速度
'auto_read_speed_step': 0.5,  # 速度调整步长
```

在 `validate_config` 方法中添加验证逻辑：
- 确保 `auto_read_speed` 在 `min` 和 `max` 之间

#### 步骤 2：更新配置窗口 (`config_window.py`)

在配置界面中添加以下内容：

**A. 添加"自动阅读设置"组**
1. 创建 `create_auto_read_group()` 方法
2. 添加速度设置滑块（范围 0.5-10 秒，步长 0.5）
3. 显示当前速度值（如 "2.0 秒/页"）
4. 将该组添加到主布局中

**B. 添加"快捷键说明"组**
1. 创建 `create_shortcuts_group()` 方法
2. 使用 QTextEdit 或 QLabel 显示所有快捷键列表
3. 格式清晰，分组显示（阅读器快捷键等）
4. 将该组添加到主布局的最后（在翻页按键设置之后）

#### 步骤 3：更新阅读器窗口 (`reader_window.py`)

这是核心部分，需要添加：

**A. 新增成员变量**
```python
# 自动阅读相关
self.auto_reading = False  # 是否正在自动阅读
self.auto_read_paused = False  # 是否暂停
self.auto_read_timer = None  # 自动阅读定时器
self.auto_read_was_paused_by_hide = False  # 标记是否因窗口隐藏而暂停
self.contents_window = None  # 目录窗口引用
```

**B. 初始化定时器**
在 `__init__` 方法中创建 QTimer 实例

**C. 新增方法**

1. `toggle_auto_read()` - 切换自动阅读状态（开始/停止）
2. `start_auto_read()` - 开始自动阅读
3. `stop_auto_read()` - 停止自动阅读
4. `pause_auto_read()` - 暂停自动阅读
5. `resume_auto_read()` - 恢复自动阅读
6. `auto_read_step()` - 自动翻页执行方法
7. `increase_auto_read_speed()` - 加快速度
8. `decrease_auto_read_speed()` - 减慢速度
9. `update_auto_read_timer()` - 更新定时器间隔
10. `show_contents_window()` - 显示目录页面并自动定位

**D. 修改右键菜单**
在 `show_context_menu()` 方法中添加：
- 添加"开始自动阅读"菜单项
- 根据当前状态动态显示文本
- 连接到 `toggle_auto_read()` 方法
- 添加"查看目录"菜单项
- 连接到 `show_contents_window()` 方法

**E. 修改键盘事件处理**
在 `keyPressEvent()` 方法中添加：
- `Ctrl + A`：调用 `toggle_auto_read()`
- `空格`：如果正在自动阅读，调用 `pause_auto_read()` 或 `resume_auto_read()`
- `↑`：如果正在自动阅读，调用 `increase_auto_read_speed()`
- `↓`：如果正在自动阅读，调用 `decrease_auto_read_speed()`

**F. 修改窗口可见性处理**
在 `update_content_visibility()` 方法中添加：
- 当窗口隐藏时，如果正在自动阅读且未暂停，则暂停并标记
- 当窗口显示时，如果之前因隐藏而暂停，则恢复自动阅读

**G. 修改窗口关闭事件**
在 `closeEvent()` 中停止自动阅读定时器

#### 步骤 4：更新目录窗口 (`contents_window.py`)

需要添加：

**A. 新增成员变量**
- `current_line_number` - 当前阅读的行号（用于定位）

**B. 修改初始化**
- 修改 `__init__` 方法，接收可选的 `current_line_number` 参数
- 在 `on_parse_finished()` 方法后调用 `highlight_current_chapter()` 进行定位

**C. 新增方法**
- `highlight_current_chapter()` - 高亮显示当前正在阅读的章节
  - 查找当前行号所在的章节
  - 滚动到该章节
  - 设置该章节为选中状态（或使用特殊样式高亮）

## 四、实现细节说明

### 4.1 自动阅读定时器实现

使用 `QTimer` 实现定时翻页：
- 定时器间隔 = `auto_read_speed * 1000`（毫秒）
- 每次超时调用 `auto_read_step()`
- `auto_read_step()` 调用 `page_down()`，如果到达末尾则停止

### 4.2 速度调节逻辑

- 默认速度：2.0 秒/页
- 最小速度：0.5 秒/页（最快）
- 最大速度：10.0 秒/页（最慢）
- 调整步长：0.5 秒
- 上方向键：速度 -= 步长（加快）
- 下方向键：速度 += 步长（减慢）

### 4.3 状态转换图

```
[停止] ←Ctrl+A→ [阅读中] ←空格→ [暂停]
                ←空格→
                ←窗口隐藏→ [暂停（因隐藏）] ←窗口显示→ [阅读中]
```

### 4.4 目录定位逻辑

目录数据结构（来自 `table_of_contents.py`）：
```python
chapter = {
    'title': '章节标题',
    'line_number': 123,  # 章节起始行号（1基）
    'char_position': 456,  # 章节起始字符位置
    'level': 1  # 章节级别（1=主章节，2=子章节）
}
```

定位逻辑：
1. 获取当前阅读的行号（`current_line_index + 1`，转换为1基）
2. 遍历章节列表，找到最后一个 `line_number <= current_line_number` 的章节
3. 将该章节设置为选中状态
4. 滚动列表使该章节可见

### 4.5 阅读器与目录窗口的交互

阅读器打开目录窗口的方式：
1. 构造 `book_info` 字典，包含文件路径等信息
2. 创建 `ContentsWindow` 实例，传入当前行号
3. 连接 `chapter_selected` 信号到跳转处理函数
4. 显示目录窗口
